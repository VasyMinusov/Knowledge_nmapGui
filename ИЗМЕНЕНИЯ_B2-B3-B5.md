# ИЗМЕНЕНИЯ B2–B3–B5 — Pip-Boy / CRT редизайн

Накопительный архив: содержит также все файлы этапов A1–A6.
Архитектура папок сохранена — файлы можно копировать поверх проекта.

## B2. Дизайн-токены
- `nmap-panel/src/tokens/colors.css` — новая палитра Pip-Boy: единый фосфорный
  цвет `--pip-fg #33ff66` на `--pip-bg #0a0f0a`, приглушённый `--pip-fg-dim`,
  «призрачный» `--pip-fg-ghost`, пара инверсии `--pip-invert-bg/--pip-invert-fg`,
  `--pip-danger`, `--pip-warning`, рамки `--pip-border(-dim)` и двойная
  `--pip-border-dbl`. Янтарная тема `[data-theme="yellow"]` (Pip-Boy amber).
  Все легаси `--color-*` оставлены алиасами на pip-токены (миграция без слома,
  удалятся на этапе B7).
- `nmap-panel/src/tokens/shadows.css` — все `box-shadow` обнулены
  (`--shadow-neon-*: none`); свечение допустимо только для текста
  (`--text-glow`, `--text-glow-dim`).
- `nmap-panel/src/tokens/typography.css` — шрифт терминала
  `'Share Tech Mono', 'VT323', monospace`, размеры `--pip-fs-*`; алиасы
  `--font-*` сохранены. Альтернатива VT323 через `[data-font="vt323"]`.
- `nmap-panel/index.html` — подключены Google Fonts (Share Tech Mono, VT323),
  заголовок «Nmap Panel».
- `nmap-panel/src/index.css` — body на pip-токенах, лёгкий фосфорный ореол
  текста, убран старый `::before`-оверлей, добавлен класс `.pip-flicker`.

## B5. CRT-эффект

## B3. Редизайн компонентов кита
Контракты пропсов и имена экспортов не изменены — потребители не тронуты.

- `IndustrialCard` — рамка 1px solid, заголовок `[ TITLE ]` слева;
  без уголков, без глитча, без motion. Вариант `accent` = двойная рамка.
- `NeonButton` — текст `[ LABEL ]`, рамка 1px, hover = инверсия
  (bg↔fg), danger-вариант инвертируется красным. Sweep и motion убраны.
- `NeonInput` — только нижняя линия, префикс `>`, мигающий блочный
  курсор `█` при фокусе (1s steps). Без box-shadow, без motion.
- `NeonSelect` — триггер как NeonInput + `▾/▴`; выпадающий список с рамкой
  1px, пункты `[x]/[ ]`, hover пункта = инверсия. Motion убран.
- `NeonCheckbox` — текстовый `[x] label` / `[ ] label`, клавиатура
  (Space/Enter), role="checkbox".
- `StatusBadge` — текстовые глифы: `●` OK / `○` OFF / `▲` WARN / `✕` ERR;
  `pulse` = то же мигание 1s, что у курсора. Без анимированных колец.
- `IndustrialTabs` — нижняя линия 1px, активный таб = инверсия с `[ LABEL ]`;
  layoutId-подчёркивание убрано.
- `IndustrialToggle` — текстовый `[ON ]/[OFF]`, role="switch", клавиатура.
- `ProgressBar` — блочный ASCII-прогресс `████░░░░ 62%` (20 блоков).
- `NeonSpinner` — ASCII-спиннер `|/-\` с кадром 100ms.
- `NeonTooltip` — рамка 1px, без анимаций; портал-логика сохранена.
- `ToastNotification` — рамка 1px, текстовые иконки `[+]/[!]/[x]`,
  закрытие `[x]`; только slide-in 120ms (steps). Таймер-полоска убрана.
- `IndustrailModal` — без уголков и пульсаций: рамка 1px (danger — красная),
  заголовок `[ TITLE ]`, закрытие `[x]`; только fade фона 150ms.
- `GlitchText` — эффект «дешифровки» убран, рендерит плоский текст
  (пропсы interval/speed сохранены для совместимости).
- `MenuItem` — текстовый пункт меню: hover и active = инверсия,
  маркер активного `◄`. Без GlitchText и layoutId-точки.
- `ScreenTransition` — анимации переходов убраны; screenKey даёт чистый
  remount экрана.
- `Avatar` — квадрат с рамкой 1px, статус глифом `●/○/▲`.
- `NeonIcon` — drop-shadow свечение убрано (классы интенсивности оставлены).
