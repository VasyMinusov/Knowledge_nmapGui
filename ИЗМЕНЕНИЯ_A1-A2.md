## A2. Реестр аудита (backend/app/audit_tools.py)

### A2.1. Категории = фазы пентеста (PTES)
- `CATEGORIES` теперь словарь метаданных `{label, order, icon, phase_hint}`:
  `recon → scanning → vuln → exploit → brute → tls → utils`.
- `list_tools()` возвращает `category_order` и `phase_hint`, сортировка:
  фаза → доступность → имя (рабочие инструменты первыми).
- `GET /api/audit/tools` отдаёт категории отсортированными, с `order/icon/phase_hint`.

### A2.2. Инструменты: 23 → 63
- **recon**: amass, findomain, whois, katana, gau, waybackurls, crtsh (через curl, JSON), dnsenum, fierce
  (+ перенесены subfinder, assetfinder, theHarvester, dnsx из osint);
- **scanning**: masscan, rustscan, naabu (JSON), dirsearch, wfuzz, enum4linux-ng, smbclient, smbmap,
  nbtscan, rpcclient, snmpwalk, ldapsearch, showmount, mtr (+ перенесены gobuster, ffuf, feroxbuster);
- **vuln**: sqlmap, xsstrike, commix, joomscan, droopescan, cmseek, arjun, sslyze, searchsploit
  (+ перенесены nikto, nuclei, dalfox, wpscan);
- **brute**: hydra, medusa, patator, ncrack, john, hashcat, cewl, crunch;
- **utils**: dig, openssl (s_client -brief), host, jq.
- Категория `exploit` пока пуста — модули Metasploit появятся на этапе A3.
- Новые `target_kind`: `query` (searchsploit, john, hashcat, jq — цель это запрос/хэш/JSON)
  и `none` (crunch — цель не нужна; `POST /api/audit/run` не требует target для них).
- Все опции из UI валидируются (`_opt_int/_opt_token/_opt_wordlist`) — словари только
  из `/usr/share/` или `/app/`, сервисы/модули — по белым спискам regex.

### A2.3. Универсальные парсеры + Finding
- `make_generic_parser(keep_re)`: `vulnerable|exploit|CVE-` → high/critical,
  `accepted|weak|…` → medium, `found|open|admin` → low, прочее — info только при
  совпадении tool-specific regex (шум отбрасывается).
- `parse_json_output`: JSON-lines и цельный JSON (nuclei/naabu/httpx/dnsx `-json`, crt.sh).
- `Finding` расширен полями `source` (id инструмента), `host`, `port` — раннер
  проставляет их автоматически (под сводную панель находок A6).
- `default_wordlist()`: приоритет SecLists (`raft-medium-directories` →
  `directory-list-2.3-medium` → `common.txt`) → системные → bundled.

## Установка инструментов (backend/install-tools.sh)

- apt (оба профиля): +`ncrack patator smbmap dnsenum fierce nfs-common samba-common-bin
  john hashcat cewl crunch wfuzz exploitdb`;
- pipx (full): +`fierce droopescan commix enum4linux-ng`;
- git-установки (full): XSStrike, CMSeeK, JoomScan — по образцу nikto, с обёртками в `/usr/local/bin`;
- бинарные релизы (full, amd64): findomain, rustscan (.deb);
- отсутствие любого пакета не роняет сборку — как и раньше, сводка пропущенного в конце.

## Фронтенд (минимально, без редизайна — он в Track B)

- `nmapApi.ts`: типы `AuditTool` (+`category_order`, `phase_hint`, `target_kind: 'query' | 'none'`),
  `AuditCategory` (+`order/icon/phase_hint`), `AuditFinding` (+`source/host/port`), тип `AuditPhase`.
- `AuditToolCard.tsx`: иконки фаз; опции под новые инструменты — словарь, потоки, расширения,
  пользователь, сервис (select SSH/FTP/RDP/…), модуль (medusa/patator), порт.
- `AuditToolkit.tsx`: для `target_kind: 'none'` кнопка запуска не блокируется пустой целью.
