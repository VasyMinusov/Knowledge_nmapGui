# Track A — этапы A3–A6: что изменено

Архив содержит **полные версии изменённых файлов** с сохранением структуры папок.
Файлы **накопительные**: включают изменения A1–A2 (прошлый архив), поэтому
можно накатывать только этот набор поверх чистого проекта.

## A3. Metasploit

### A3.1. Профиль сборки max (backend/install-tools.sh)
- Новая ветка `TOOLS_PROFILE=max`: SecLists (`git clone --depth 1` → `/usr/share/seclists`,
  поддержка `SECLISTS_MIRROR` для закрытого контура) + Metasploit Framework
  (официальный инсталлятор Rapid7; работает без PostgreSQL — scanner/auxiliary
  модули доступны, db_* — нет). Сборка: `make build-max`.
- В `docker-compose.yml` и шапке скрипта задокументирован профиль `max`.

### A3.2. Модули MSF как карточки (категория exploit, 8 инструментов)
`msfconsole -q -n -x "use <module>; set …; run; exit"`:
- `msf_http_version`, `msf_smb_version`, `msf_ssh_version`, `msf_ftp_version` — сканеры версий;
- `msf_vsftpd_backdoor` — проверка бэкдора vsftpd 2.3.4;
- `msf_smb_ms17_010` — EternalBlue checker;
- `msf_ssh_login` — брутфорс SSH со словарём SecLists;
- `msf_custom` — произвольный модуль (advanced): опции `module` и `options_str`
  (только строки вида `set KEY VALUE`, RHOSTS защищён от переопределения).
- Парсер `parse_msf_generic`: `The target … vulnerable` → high, `session … opened` →
  critical, `Exploit completed` → medium, `Login Successful` → high, `is running` → info.

### A3.3. MSFVenom — POST /api/payloads/generate
- Тело: `{payload, lhost, lport, format}` — всё валидируется (payload по белому regex,
  lport 1–65535, format из 12 форматов). Файл пишется в `audit_runs/payload_<ts>.<ext>`,
  в ответе — `download_url` (`GET /api/payloads/download/{filename}` с защитой от path traversal).
- UI: карточка **«PAYLOADS (MSFVENOM)»** в инструментарии аудита (payload, LHOST, LPORT,
  формат, ссылка на скачивание).

### A3.4. MSF RPC — не делалось
Опциональный пункт V3 (msfrpcd + pymetasploit3) — отложен, как и предусмотрено планом.

## A4. SecLists

### A4.1/A4.2
Установка — в профиль `max` (см. выше); `default_wordlist()` уже с A2 предпочитает
`raft-medium-directories.txt → directory-list-2.3-medium.txt → common.txt`.

### A4.3. GET /api/audit/wordlists
Категории `directories`, `usernames`, `passwords`, `params`, `subdomains` + `generated`
(созданные cewl/crunch). Сканирование `/usr/share/seclists` и `/usr/share/wordlists`
при первом обращении, кэш 1 час, до 200 записей на категорию.

### A4.4. UI — селекты словарей
В `AuditToolCard` для gobuster/ffuf/feroxbuster/dirsearch/wfuzz/dnsenum/hydra/medusa/
patator/ncrack/john/hashcat текстовое поле заменено на `<select>` со словарями из API
(с размером файла; fallback на текстовое поле, если API недоступно). Для hydra —
отдельное поле `-L` (список логинов из `usernames`) в дополнение к `-P`.

### A4.5. Генерация словарей
`cewl` (`-w`) и `crunch` (`-o`) сохраняют результат в `audit_runs/wordlists/` —
файлы появляются в категории `generated` и во всех селектах словарей.

## A5. Терминал

- `ALLOWED_BINARIES` += `msfconsole`, `msfrpcd`, `crunch` (остальное из списка A5 там уже было).
- `terminal_catalog.py`: конструкторы для `searchsploit`, `wfuzz`, `dirsearch`,
  `enum4linux-ng`, `msfvenom` (включая слитные флаги `LHOST=`/`LPORT=`,
  `-l payloads|encoders|formats`). `msfconsole` — только raw-режим, быстрые примеры
  оставлены комментарием в каталоге.
- `FlagBuilder.tsx`: иконки новых категорий-фаз (scanning/vuln/exploit/utils).

## A6. Новые API

| Endpoint | Статус |
|---|---|
| `GET /api/audit/wordlists` | ✅ категории словарей с кэшем 1 ч |
| `GET /api/audit/suggestions?scan_id=X` | ✅ рекомендации по портам/сервисам/whatweb/wafw00f |
| `GET /api/audit/findings?scan_id=X` | ✅ сводная таблица находок + счётчики по severity |
| `POST /api/payloads/generate` | ✅ msfvenom → файл + ссылка на скачивание |

Логика `/suggestions`: http/80/443/8080… → whatweb/wafw00f/gobuster/nikto/nuclei;
443 → sslscan/testssl; 22 → msf_ssh_version + hydra-ssh; 21 → msf_ftp_version + hydra-ftp;
445/139 → enum4linux-ng/smbmap/msf_smb_ms17_010; 3389 → hydra-rdp; 3306/5432 → hydra-mysql/postgres;
161 → snmpwalk; 389 → ldapsearch; 2049 → showmount; WordPress/Joomla/Drupal в whatweb →
wpscan/joomscan/droopescan; WAF обнаружен → dalfox с `--waf-evasion` (опция `waf_bypass`).
Уже запущенные (tool, target) и недоступные инструменты не предлагаются.

UI: строка чипов **«Рекомендуемые действия»** под полем цели (клик — запуск с целью
и опциями из рекомендации) и карточка **«Сводка находок»** (счётчики по severity +
таблица до 100 строк: severity · источник · host:port · находка).
