## B7. Что сделано

### Миграция на pip-токены (удаление легаси)
- Все `--color-*` в 30+ CSS/TSX заменены на `--pip-*`
  (bg→--pip-bg, text-primary→--pip-fg, text-secondary/muted→--pip-fg-dim,
  accent→--pip-fg, danger→--pip-danger, border→--pip-border и т.д.).
- `--font-mono/--font-display` → `--pip-font`, `--font-size-*` → `--pip-fs-*`,
  `--letter-spacing-wide` → 1px, `--shadow-*` → none.
- Блоки легаси-алиасов удалены из tokens/colors.css и tokens/typography.css;
  tokens/shadows.css оставляет только --text-glow(-dim).
- Удалён сиротский модуль `nmap-panel/src/tokens/motion.ts`
  (импортов не оставалось с этапа B6).

### Зачистка визуальных остатков
- Хардкод-hex в CSS переведены на токены (#66ff33→--pip-fg,
  #ff5555→--pip-danger, #ffb800/#ffcc33→--pip-warning, старые фоны→--pip-bg).
- `border: Npx ridge` → `1px solid` (OptionCard, CommandExplainer, PresetManager).
- Все `box-shadow` объявления удалены из CSS компонентов; box-shadow вычищен
  и из transition-списков.
- Старые RGBA-оттенки зелёного унифицированы к фосфорному rgb(51,255,102).
- Убрана мёртвая переменная --color-bg-router (легенда D3-графа).
- Severity-цвета сводки находок: critical=--pip-danger, high=--pip-warning —
  критичные и высокие теперь различимы.
- TopologyGraphD3: цвета графа возвращены к конкретным значениям
  (var() в SVG-атрибутах ненадёжен; палитра и так theme-aware через isGreen).

### Проверки
- `npx tsc -b` — без ошибок.
- `pnpm build` — успешно (JS ~745 kB / gzip ~244 kB).
- Визуальная QA (headless-скриншот): сайдбар-меню с инверсией активного
  пункта, статус-бар, карточки [ TITLE ], текстовые [x]-чекбоксы, сканлайны —
  всё рендерится корректно в обоих разрешениях сетки.
- Финальный grep-sweep: --color-*, --font-*, --shadow-*, ridge, outset,
  motion — чисто (0 совпадений в src).
